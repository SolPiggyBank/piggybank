# Security policy

PiggyBank holds people's keys, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue** for a security problem. Report it privately instead:

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability** and describe the issue: what is affected, how to reproduce it and what an attacker could do.

You can expect a first reply within a few days. Please give us a reasonable time to fix the issue before disclosing it publicly.

## Scope

- The extension's code in this repository: key generation and storage, vault encryption, transaction building and checks, swaps, locks, RPC handling.
- The published Chrome Web Store build of PiggyBank.

Out of scope: third-party programs and services PiggyBank uses (Solana, Jupiter, Jupiter Lock, public RPC nodes). Please report those to their own teams.

## Staying safe

- Install PiggyBank only from the [Chrome Web Store](https://chromewebstore.google.com/detail/piggybank/keijhgciggnmkpocaadohnknkeacgonp) or the link on [solpiggybank.com](https://solpiggybank.com).
- PiggyBank never DMs first and never asks for your recovery phrase or private key.
